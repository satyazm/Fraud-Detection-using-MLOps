# docs/

- `architecture.md` — system architecture, layering, target data flow.
- `decisions/` — Architecture Decision Records (ADRs), one immutable file
  per significant decision. Start at `0001-record-architecture-decisions.md`.
- `data_report.md` + `images/` — the PaySim data quality report and its
  plots, generated by `fraud-detection validate` (or `make validate`).
  Generated, not hand-written — rerun the command instead of editing.

Model-specific documentation (model cards, evaluation reports) will be
added here starting Phase 3.
